# app-selling-bot

Minimal Telegram bot UI for showing app stock counts.

## Setup

1. Create a bot with BotFather and get a token.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Run the bot:

```bash
export BOT_TOKEN="YOUR_TOKEN_HERE"
python bot.py
```

## Customize

Edit the `APP_STOCK` values in `bot.py` to change the apps and counts.
